作れる図

図の作成

状態遷移図・ブロック図・論理回路をマウスで描く。論理ゲート(AND・OR・NOT・NAND・NOR・XOR・D フリップフロップ)と、縦横に自動で引ける配線。

散布図と回帰直線

Excel / CSV を読み込んで点を重ねて描き、最小二乗法の回帰直線。傾き・切片(± 標準誤差)・R²・相関係数・p 値を表で出してコピー。

レポート用の図

大きさを cm で決めて、線・点・誤差棒・近似直線のグラフ。白黒印刷でも見分けられる形と線の種類、明朝体にも対応。

3 ステップで完成

  1. 開く上のボタンから、作りたい図の画面を開きます。登録はいりません。
  2. 作る図形を置く、または Excel / CSV をドラッグ。ラベルは $10^{-3}$ や $\alpha$ のように LaTeX の書き方で数式にできます。
  3. 保存する「書き出す」から PDF / PNG / SVG で保存。LaTeX には PDF、Word には PNG がおすすめです。

特長

💰 無料・登録不要ブラウザで開くだけ。インストールもいりません。

よくある質問

本当に無料ですか? 登録はいりますか?

無料で、登録もいりません。ブラウザでページを開くだけで使えます。

作った図を LaTeX のレポートに入れられますか?

はい。「書き出す → PDF」で保存して、\includegraphics{fig1.pdf} のように読み込めます。文字は線に変えて書き出すので、どのパソコンでも同じ見た目になります。

Excel のデータから散布図と回帰直線を作れますか?

はい。Excel(.xlsx / .xls)や CSV を読み込んで、横軸と縦軸の列を選ぶだけで、散布図と回帰直線を描きます。傾き・切片とその標準誤差、決定係数 R²、相関係数 r、p 値も表で出ます。計算に使う x の範囲も決められます。

論理回路や状態遷移図も描けますか?

はい。AND・OR・NOT・NAND・NOR・XOR・XNOR・バッファ・D フリップフロップを置いて、配線を縦横に自動で引けます。状態遷移図の「状態」と矢印(直線・曲線・自分に戻るループ)も描けます。

誤差棒つきのグラフや、白黒印刷用のグラフは作れますか?

「レポート用の図」で作れます。誤差の列を選ぶと誤差棒がつきます。白黒印刷向けにすると、色の代わりに点の形と線の種類で区別します。図の大きさは cm で決められます。

データはどこに保存されますか?

あなたのブラウザの中だけです。インターネットの向こう(サーバー)には送られません。別のパソコンで使うときは「ファイル → バックアップを書き出す」で持ち運べます。
