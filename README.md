# 実験データ グラフ作成ツール(Web 版)

ブラウザだけで動く、実験レポート用の図を作るツールです。サーバーは使いません。作った図はブラウザの中(IndexedDB)に保存されます。

## いま使えるもの
- **図の作成**(`diagram.html`):楕円・四角・注釈・文字・矢印・論理ゲートを置いて、PNG(300 dpi)/ SVG / PDF で書き出す
  - 自動保存・図の一覧・開く・削除・一時保存と「戻す」・バックアップ(JSON)の書き出し / 読み込み
  - 文字の中の `$...$` は数式(MathJax)
  - 書き出すときは文字を輪郭の線に変えるので、どの端末・PDF でも同じ見た目になる
- **散布図**(`scatter.html`):Excel / CSV を複数読み込み、点を重ねて描き、回帰直線を引く
  - シートの選択・上から飛ばす行数(自動で見つける)・UTF-8 / Shift_JIS・全角数字やカンマつき数字
  - 表で値を直せる(元のファイルは変わらない)
  - 「元のファイル」の画面で、CSV / Excel をそのまま見て、グラフに使う範囲をマウスで選べる(1 つのシートに並んだ表を別々のデータとして足すこともできる)
  - 回帰直線:計算に使う x の範囲、範囲外の点は白抜き。傾き・切片(± 標準誤差)、R²、r、p 値。結果の表はコピーできる
  - 軸:グリッド、範囲の指定と「データに合わせる」、対数目盛り、目盛りの数字の桁数、指数表記(× 10ⁿ)
  - 自動保存して「開くグラフ」から開き直せる。バックアップには作図と散布図がまとめて入る

## 手元で動かす
ファイルを直接ダブルクリックで開くと動きません(ブラウザの決まりで、部品を読み込めないため)。このフォルダで次を実行して、表示されたアドレス(http://localhost:8765)を開きます。

```bash
python3 -m http.server 8765
```

## 公開(Cloudflare Pages)
枝分かれ `main` の中身が、そのまま https://graph-tool-web.pages.dev/ で公開されます。`main` に送ると、Cloudflare が自動で公開し直します。変換の手順はありません。

## フォルダ
| 場所 | 中身 |
|---|---|
| `index.html` | 入口のページ |
| `help.html` | 使い方 |
| `privacy.html` | プライバシーポリシー(広告を入れるときは書き足す) |
| `css/page.css`, `favicon.svg` | 読むページ(入口・使い方・プライバシーポリシー)の見た目、サイトのアイコン |
| `diagram.html`, `css/diagram.css` | 作図のページ |
| `scatter.html` | 散布図のページ |
| `css/datapage.css`, `js/datapage.js` | Excel / CSV からグラフを作るページの共通部分(読み込み・データの表・元のファイル・軸の設定・自動保存・書き出し) |
| `css/common.css`, `js/ui.js` | どのページでも使う見た目・部品(お知らせ・小窓・バックアップ・数式の書き方) |
| `js/diagram/editor.js` | 作図エディタ本体(描く・動かす) |
| `js/diagram/app.js` | 上の帯(一覧・保存・一時保存・書き出し・バックアップ) |
| `js/store.js` | ブラウザ内への保存(IndexedDB) |
| `js/text.js` | 文字と数式の並べ方(画面・書き出し共通) |
| `js/prims.js` | 描く図形の一覧を SVG にする(画面・書き出し共通) |
| `js/scatter/app.js` | 散布図の画面(設定・自動保存・書き出し) |
| `js/scatter/plot.js` | グラフを描く(軸・目盛り・凡例・点の形・線の種類・誤差棒) |
| `js/scatter/data.js` | Excel / CSV の読み込みと、数値への直し方 |
| `js/scatter/stats.js` | 回帰直線と p 値(t 分布)の計算 |
| `js/export.js` | PNG / SVG / PDF の書き出し |
| `vendor/` | 同梱の部品:MathJax 3.2.2、jsPDF 2.5.2、svg2pdf.js 2.2.4、opentype.js 1.3.4、SheetJS 0.20.3(それぞれのライセンスも同梱) |
| `fonts/` | Noto Sans JP(SIL Open Font License) |
